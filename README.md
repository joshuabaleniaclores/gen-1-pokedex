# Gen 1 Pokedex

A React + TypeScript Pokedex built using PokeAPI.

## Tech Stack

- React
- TypeScript
- Vite
- TailwindCSS
- React Router
- TanStack Query
- Axios
- shadcn/ui

## Features

- Gen 1 Pokemon
- Grid/List view
- Search
- Pagination
- Pokemon details
- Capture Pokemon
- Nickname and capture date
- LocalStorage persistence
- Responsive design

## Installation

npm install
npm run dev
